# RGB 灯光含义说明（BMCU-C v3.2.1-fix105）

BMCU 共有两类 RGB 灯：

- **系统灯（SYS_RGB）**：1 颗，指示开机自检与总线/通讯状态。
- **通道灯（RGBOUT[0..3]）**：每料槽 1 颗，共 4 槽，指示该槽运行/装载状态。

本文档根据 `src/Motion_control.cpp`（`MC_STU_RGB_set` / `MC_STU_RGB_set_latch`）与 `src/main.cpp`（系统灯自检）的实际调用整理，颜色以固件写入的 RGB 数值为准（0xRR,0xGG,0xBB，范围 0–255）。

> 说明：`MC_STU_RGB_set_latch(ch, r, g, b, now, blink)` 中最后一个参数 `blink`：
> - `0` = 常亮；
> - `1` = 闪烁（由底层按固定周期切换亮/灭）。

## 颜色速查表（通道灯）

| 颜色（RGB 值） | 颜色描述 | 含义 |
|------|-----------|------|
| `0x00,0x00,0x00` | 灭 | 该槽空闲、无料、未插入 |
| `0x38,0x35,0x32` | 灰白（接近白） | 已装载（料在位、待命） |
| `0xFF,0xFF,0x00` | 黄（常亮） | 自动装载 / 检测中 |
| `0xFF,0x00,0x00` | 红（常亮） | 故障 / 卡料失败 / 失载 / 过载告警 |
| `0x00,0xB0,0xFF` | 蓝（常亮） | 使用中（on_use，正在配合打印机送料） |
| `0x00,0xD5,0x2A` | 青绿（常亮） | 送出中（send_out，正向挤出机送料） |
| `0xA0,0x2D,0xFF` | 紫（闪烁） | 退料中（pull_back） |
| `0xFF,0x00,0xFF` | 品红（闪烁） | 回抽中（pulling_back，双开关自动回抽） |
| `0xFF,0xA0,0x00` | 橙（闪烁） | 前抽中（before_pull_back，过五通前的微调退料） |
| `0xFF,0x00,0x00` | 红（常亮，低料告警覆盖） | 低料告警（g_on_use_low_latch，料快用完） |

## 各状态详细说明

### 1. 空闲 / 无料 —— 灭
- 条件：槽未插入耗材、或双开关模式下 `dm_loaded==0` 且未触发自动装载。
- 表现：灯灭。
- 代码：`MC_STU_RGB_set_latch(..., 0x00,0x00,0x00, ...)`。

### 2. 已装载待命 —— 灰白 `0x38,0x35,0x32`
- 条件：耗材已装载到位（`dm_loaded!=0` 且开关检测到料、`filament_channel_inserted` 成立），处于 idle。
- 表现：常亮灰白（肉眼接近白色，亮度较低）。
- 代码：`MC_STU_RGB_set_latch(..., 0x38,0x35,0x32, ..., 0u)`。

### 3. 自动装载 / 检测中 —— 黄 `0xFF,0xFF,0x00`
- 条件：插入耗材触发 S1 后进入自动装载状态机（`DM_AUTO_S1_DEBOUNCE` / `S1_PUSH` / `S2_PUSH` 等），
  正在自动送料约 12cm 定位。
- 表现：常亮黄。
- 代码：`MC_STU_RGB_set(CHx, 0xFF,0xFF,0x00)`。
- 注：若自动装载失败（退料失败 / 超时），会转入故障红（见下）。

### 4. 故障 / 卡料 / 失败 —— 红 `0xFF,0x00,0x00`
- 条件（任一）：
  - 双开关自动装载失败锁存 `dm_fail_latch`；
  - 低料告警 `g_on_use_low_latch`（料快用完，强制红覆盖）；
  - 自动装载流程中检测到的失载 / 过载等异常。
- 表现：常亮红。
- 代码：`MC_STU_RGB_set(CHx, 0xFF,0x00,0x00)` / `MC_STU_RGB_set_latch(..., 0xFF,0x00,0x00, ...)`。
- 排除方法：拔出耗材、重启 BMCU，或重新插入触发再次自动装载。

### 5. 使用中（配合打印机送料）—— 蓝 `0x00,0xB0,0xFF`
- 条件：打印机正在用该槽料，`motion == on_use`（压力协同控制中）。
- 表现：常亮蓝。
- 代码：`MC_STU_RGB_set_latch(num, 0x00,0xB0,0xFF, ..., 0u)`。

### 6. 送出中（正向挤出机送料）—— 青绿 `0x00,0xD5,0x2A`
- 条件：`motion == send_out`，正把料往挤出机方向送。
- 表现：常亮青绿。
- 代码：`MC_STU_RGB_set_latch(num, 0x00,0xD5,0x2A, ..., 0u)`。
- 若此时仍卡在 `g_on_use_jam_latch`（堵料锁存）且缓冲未回落，同样显示青绿但电机已停（见 README 的 v3.2 优化说明：黄灯避让 / 红灯真堵）。

### 7. 退料中 —— 紫（闪烁）`0xA0,0x2D,0xFF`
- 条件：`motion == pull_back`，打印机要求退料，BMCU 把料往回抽。
- 表现：闪烁紫。
- 代码：`MC_STU_RGB_set_latch(num, 0xA0,0x2D,0xFF, ..., 1u)`。

### 8. 回抽中（双开关自动回抽）—— 品红（闪烁）`0xFF,0x00,0xFF`
- 条件：`filament_now_position == filament_pulling_back`，双开关模式下按 S2 检测料根位置自动回抽。
- 表现：闪烁品红。
- 代码：`MC_STU_RGB_set_latch(i, 0xFF,0x00,0xFF, ..., 1u)`。

### 9. 前抽中（过五通前微调退料）—— 橙（闪烁）`0xFF,0xA0,0x00`
- 条件：`motion == before_pull_back`，使用送料中在退料前先微量回抽以判断缓冲头位置。
- 表现：闪烁橙。
- 代码：`MC_STU_RGB_set_latch(num, 0xFF,0xA0,0x00, ..., 1u)`。

### 10. 暂停 / 停止（stop_on_use）—— 红 `0xFF,0x00,0x00`
- 条件：打印机发来暂停/停止指令（`motion == stop_on_use`）。
- 表现：常亮红（表示已停，等待恢复）。
- 代码：`MC_STU_RGB_set_latch(num, 0xFF,0x00,0x00, ..., 0u)`。
- 注：v3.2 已修复"暂停后 BMCU 仍继续转"的问题，收到暂停即切到此状态并停机。

## 状态流转示意（单个料槽）

```
  无料(灭) ──插入触发S1──▶ 自动装载(黄) ──成功──▶ 已装载(灰白)
                                  │
                                  └──失败──▶ 故障(红) ──重插/重启──▶ 自动装载(黄)

  已装载(灰白) ──打印机选用──▶ 使用中(蓝) ──送料──▶ 送出中(青绿) ──完成──▶ 已装载(灰白)
                    │                                      │
                    └──暂停/停止──▶ 红(停) ──恢复──▶ 使用中(蓝)

  使用中/送出中 ──退料──▶ 前抽(橙闪) ──▶ 退料(紫闪)/回抽(品红闪) ──▶ 无料(灭) 或 重新装载(黄)
```

## 系统灯（SYS_RGB）开机自检与上电时序

系统灯用于开机自检与总线状态，与 4 颗通道灯互不冲突。每次上电都会先跑一段**不阻塞主程序**的自检（`src/main.cpp` 中 `g_aht20.init()` + `read_blocking()`）。

### 上电灯序对照（实机现象）

| 阶段 | 系统灯 | 含义 |
|------|--------|------|
| 开机固定 | 红（短亮） | 正常启动红灯 |
| AHT20 自检 | **蓝 → 绿（短亮）** | 蓝=检测到 AHT20 存在；绿=成功读到一次温湿度（v3.2.1-fix105 修复后可见） |
| 校准/初始化 | 灭（首次久、二次快） | 首次开机含校准耗时较长；二次开机已校准则很快 |
| 进入主循环 | 浅灰 `0x38,0x35,0x32` | 正常心跳 |
| 总线/通讯错误 | 红 `0x10,0,0` | 收到 error 包（与 AHT20 无关，属原有通讯逻辑） |

> 自检蓝→绿亮过即说明 AHT20 驱动修复成功、传感器在线可读；若自检不亮灯（直接灭→进主程序），表示未检测到 AHT20 或未焊接，不影响换料/通讯，温湿度按默认 22℃/20% 上报。

### 系统灯颜色速查

| RGB 值 | 含义 |
|--------|------|
| `0x10,0x00,0x00` | 红灯：开机启动 / 总线通讯错误 |
| `0x00,0x00,0x10` | 蓝灯（短）：AHT20 自检检测到存在 |
| `0x00,0x10,0x00` | 绿灯（短）：AHT20 自检成功读到温湿度 |
| `0x38,0x35,0x32` | 浅灰：正常心跳 / 在线待命 |
