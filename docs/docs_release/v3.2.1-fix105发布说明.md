# BMCU-C 固件发布说明 —— v3.2.1-fix105

> 适用机型：BMCU 切料机（CH32V203C8T6 / RISC-V 版）
> 固件向打印机上报的版本号保持 `10.50`，兼容性不变，可直接替换旧版使用。
> 本版基于 v3.2-fix105 发展，**只修 AHT20 温湿度传感器驱动、不改任何换料/回抽功能**，原有特性全部保留。
> 版本向下兼容：3.0 系列仍支持 2.0 系列新增的 AHT20 温湿度传感器功能。
---

## 一、本次更新了什么

### 1. 修复「AHT20 读不到温湿度」的问题（核心修复）

- **现象**：旧版（v3.2 及之前）上电自检只能亮红灯，打印机里 AMS 温湿度长期显示默认的 **22℃ / 20%**，等于 AHT20 装了也白装。
- **原因**：旧驱动在传感器初始化时，发了 `0xBA`、`0xE1 0x08 0x00` 这类**AHT20 官方手册上根本不存在的指令**。给刚上电的传感器发未知命令，会让它进入异常状态，之后真正的测量命令 `0xAC` 一直不应答，自检必失败。
- **修复**：
  - 彻底移除这些无效指令，上电即就绪，直接发官方标准测量命令。
  - 严格按官方手册时序：上电等 5ms → 发写测量命令 `0x70 0xAC 0x33 0x00` → 等 ≥80ms → 发 `0x71` 读 7 字节（状态字 + 湿度 20 位 + 温度 20 位 + CRC）。
  - 软件 I2C 底层按验证过跑通的测试程序重写：SDA/SCL 全程开漏（读 SDA **不切输入模式**，靠外部 4.7k 上拉读取），避免电平冲突导致读不到。

### 2. 新增「开机 AHT20 自检灯」（方便你确认传感器好坏）

- 每次上电，BMCU 都会**先**检查 AHT20（在校准动作之前），检查过程**不影响主程序**：
  - 系统灯亮 **蓝灯** —— 检测到 AHT20 存在；
  - 系统灯亮 **绿灯** —— 成功读到一次温湿度（说明传感器在线、能正常工作）；
  - 都没亮就直接进主程序 —— 表示没检测到 AHT20（多半是没焊接），不影响换料，温湿度按默认 22℃/20% 上报。
- 自检通过后，固件会持续每 2 秒刷新一次温湿度，由打印机自动读取并显示**真实温湿度**。
- 上电灯序与各灯含义见 [`../rgb_led_meaning.md`](../rgb_led_meaning.md)。

### 3. AHT20 在线判定

- AHT20 状态字里**没有厂商 ID 位**，没法靠读 ID 确认型号，所以 3.2.1 用下面几道关来判断板子上有没有焊 AHT20：
  - **校准使能位（bit[3]）**：传感器上电后硬件自动置 1，软件写不了也清不掉，是最可靠的「芯片真存在」指纹，没这位基本就是噪声。
  - **物理范围**：湿度必须在 0–100%、温度必须在 −40–85℃，越界就是垃圾数据。
  - **忙标志（bit[7]）**：测量没完成时为 1，这种读数作废。
- 上电自检发 **5 次**测量命令，任一次通过上面校验就认在线；5 次全败认无传感器。
- 工作中若**连续 10 次**采样都失败，自动当成传感器掉了，温湿度走默认 22/20、停止采样；中间成功一次就恢复。

### 4. 系统灯逻辑

- AHT20 在板子上离 SYS_RGB 灯珠很近，灯一直亮白光会发热、把读数烤高，所以改成：
  - **焊了 AHT20 的板子**：系统灯**每 3 秒闪一下白光（约 150ms）**，其余时间熄灭——保留在线可见，又不持续烤温。
  - **没焊 AHT20 的板子**：白色常亮（没传感器可烤，保持原样）。
  - **通讯异常**：红色常亮。

## 二、你需要做什么

1. **如果你已经焊接了 AHT20**：直接刷本版固件，上电看系统灯——蓝→绿闪一下即说明修复成功，打印机里温湿度会变成真实读数。
2. **如果你还没焊接 AHT20**：刷本版也完全正常，只是自检灯不亮、温湿度显示默认 22℃/20%，换料/回抽功能不受影响。
3. **回抽方式、送料逻辑、暂停停机等**均沿用现有设计，无需重新配置：双开关板用 S2 自动判定料根，单开关板按固定回抽长度编译。

## 三、固件包说明

BMCU 固件按「回抽方式」分两类发布包，选错会导致退料长度不对：

| 包类型 | 说明 | 适用板型 |
|---|---|---|
| 自动回抽长度包（`firmwares-auto`，文件名含 `_auto`） | 双开关板用 S2 微动开关自动判定料根位置，退料长度自适应 | 双微动开关板 |
| 固定回抽长度包（`firmwares-fixed`，文件名不含 `_auto`） | 按 PTFE 管长度固定编译退料长度 | 全部板型；单开关板只能用此包 |

两类包都包含本次 AHT20 修复，区别仅在于退料长度如何确定。

具体选型对照见仓库根目录 [`which_to_choose_filament_rgb.txt`](../../which_to_choose_filament_rgb.txt)、[`which_to_choose_autoload.txt`](../../which_to_choose_autoload.txt)、[`which_to_choose_slots.txt`](../../which_to_choose_slots.txt)、[`which_to_choose_mode.txt`](../../which_to_choose_mode.txt)。

## 四、开发细节与排错

- 代码层面改动仅限 `src/aht20/aht20.h`、`src/aht20/aht20.cpp`（多重在线判定、5 次自检、运行期失败计数）、`src/main.cpp`（开机自检 + 系统灯心跳状态机），3.2 核心功能代码未动。
- 自检蓝→绿亮过即说明驱动修复成功；之后若系统灯常亮红灯，是 BMCU 与打印机握手报错（与 AHT20 无关，属原有通讯逻辑）。焊 AHT20 的板子进入主循环后系统灯每 3 秒闪一下白光即正常，非故障。
- 更多实现细节见 [`../BMCU开发说明.md`](../BMCU开发说明.md) 第 12 章。
