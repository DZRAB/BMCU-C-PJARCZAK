# BMCU-C 固件发布说明 —— v4.0-tpu

> 适用机型：BMCU 切料机（CH32V203C8T6 / RISC-V 版）
> 本固件向打印机上报的机型标识为 **`N3F05`**，上报版本号保持 `10.50`，兼容性不变。
> 本版重点是**稳定性增强与可观测性**：新增可选 OLED 状态屏、修复 AHT20 温湿度稳定性、修复电机啸叫、新增系统灯通讯心跳、新增打印完成自动重启、整理编译开关文档。**TPU 软料送料为实验性功能，仍在开发中、效果尚未稳定，见文末。**

---

## 一、本次更新了什么（重点）

- **新增可选 OLED 状态屏**：焊一颗 0.96" I2C OLED，即可在 BMCU 上肉眼看温湿度、通讯状态、四通道料况，**不上机也能显示**。详见第五节。
- **AHT20 温湿度稳定性修复**：重写上电自检与读取流程，修复旧版偶发的读不到 / 误报离线问题，识别更可靠。未焊 AHT20 时走默认温湿度，行为一致。
- **电机啸叫修复**：PWM 载波由约 18kHz 提升至 36kHz，超出人耳听感上限，消除送料时的尖锐啸叫（全材质受益）。
- **主板系统灯（SYS_RGB）通讯心跳**：系统灯显示 BMCU 与打印机通讯状态（有 AHT20 时每 3 秒闪一下白光、无 AHT20 时常亮白光、通讯异常时红色），一眼判断通讯是否正常。
- **新增打印完成自动重启**：打印结束、本机及总线所有 AMS 均 idle 持续 30 秒后，BMCU 自动假离线 10 秒再软复位，相当于模拟拔插重连，避免长期运行后状态粘滞。由 `BMCU_AUTO_REBOOT_ENABLE` 总开关控制（默认开，测试时可关）。
- **若干 bug 修复**：包括 OLED 关闭路径编译报错修复、RGB / 通讯若干边界问题修复。
- **编译开关文档化**：编译传参与手动改文件两类开关整理为对比表（见 `docs/编译指南.md` 第 16.3 节）。

> 以上功能均已稳定可用，是本次推荐升级的主要理由。机型标识为 `N3F05`（可让 Bambu Studio 显示温湿度数值），详见第六节说明。

## 二、怎么选固件（刷哪一个）

**只有一套固件**，不再区分通用/专用。按三点选：**板型**、**打印机模式**、**PTFE 长度**，外加可选的 **OLED 开关**与 **4 通道写死型号（TPU 实验用）**。

1. **板型**：双开关 = AUTOLOAD；单开关 = NO_AUTOLOAD。
2. **打印机模式**：standard / p1s / soft_load(A1)。
3. **PTFE 长度档**：见 `which_to_choose_slots.txt`。
4. **（可选）OLED 状态屏**：编译时给 `build_one.sh` 第 11 参数传 `1`；不传则与无屏版完全一致。
5. **（可选）4 通道写死型号**：需要 TPU 实验时编译传 `BMCU_TPU_FIX0~3`，不传默认全 `GFU85`。

> 文件名示例：`firmwares/standard(A1)/AUTOLOAD/FILAMENT_RGB_ON/AMS_A/ams_a_0.30f.bin` = 标准推力 / 双开关 / 槽 A / 0.30m 回抽。

## 三、主板系统灯（SYS_RGB）通讯状态

> 这是**主板上单独一颗灯**，不是各料槽的通道灯，只显示 BMCU 与打印机的通讯状态。

| 状态 | 颜色 | 含义 |
|---|---|---|
| 启动瞬间 / 首心跳前 | 红（短亮） | 刚上电，未建立通讯 |
| 通讯正常 + 无 AHT20 | 浅灰白（常亮） | 心跳正常 |
| 通讯正常 + 有 AHT20 | 浅灰白 **每 3 秒闪一下** | 避免灯珠发热烤高读数 |
| 通讯失败 | 红（常亮） | 与打印机掉线 / 总线错误 |

系统灯变**红** = 掉线，按原通讯问题排查。

## 四、怎么看 BMCU 内部实际型号（RGB 灯自检，配合 TPU 实验）

关掉「耗材颜色显示」后，通道灯（每槽一颗）显示 **BMCU 内部实际跑的型号**（写死型号），不是打印机下发的 `GFU98`。

| 内部型号 | 硬度 | 通道灯颜色 |
|---|---|---|
| GFU98（TPU for AMS） | 68D | 青 |
| GFU00（TPU 95A HF） | 95A | 绿 |
| GFU02（Generic TPU） | 约 68D | 紫 |
| GFU95（TPU 95A） | 95A | 黄 |
| GFU90（TPU 90A） | 90A | 橙 |
| GFU85（TPU 85A） | 85A | 红 |
| 非 TPU（PLA / PETG / ABS / PA / 未知 / other） | — | 白偏蓝（统一色） |

用途：写死 `GFU90` 却显示白偏蓝 → 该通道没被设为 TPU，写死表未生效（正常）；显示橙色 → 内部确在按 `GFU90` 跑。开「耗材颜色显示」时灯显真实耗材色，此表不生效。

## 五、可选 OLED 状态屏（`BMCU_OLED`）

焊一颗 0.96" I2C OLED（复用 AHT20 的 PB10/PB11 软件 I2C，不新增引脚），即可肉眼看状态，**不上机也能显示**：

- **启用**：编译时 `build_one.sh` 第 11 参数传 `1`；不传则固件与无屏版完全一致（运行时自动探测屏，无屏零影响）。
- **显示内容**（多页 1Hz 轮询，屏上从左到右记作第一 / 二 / 三页）：
  - **第一页**：温湿度 + 通讯状态 + 写死型号摘要（`LOCK: 98/90/95/85`）。
  - **第二页**：四通道概览，按实际通道 **1~4** 列出各通道状态与料型（屏上显示 1:/2:/3:/4:，对应内部通道 0~3）。
  - **第三页**：通讯调试信息（`PKG` 收包计数 / `SET` 设料次数 / `ID` 最近 filament_id）+ 运行时长。
  - **动作插队**：有进料 / 退料动作时，临时插队显示动作页（通道号同样按 1~4），动作结束回到轮询。
  - **调试用途**：第三页是通用通讯调试窗口。`PKG` 持续上涨说明 BMCU 与打印机通讯正常、没漏包；`SET` 反映打印机下发的设料指令次数；`ID` 显示最近一次收到的料号。排查通讯掉线、设料没生效、打印机暂停/停止 BMCU 是否收到指令等问题，都可以对照这三行观察。
- **热插拔**：开机插拔均无需重启，带电拔掉熄灭、重插自动点亮。
- 当前刷新率 1Hz 整屏重绘（有"逐帧"感，不影响性能），后续会优化。

## 六、刷写与兼容性

- 刷写用 **WCHISPTool**（不要用 BMCU Flasher，本仓库固件用它刷会失败）。
- 上报版本保持 `10.50`，机型标识 **`N3F05`**（可让 Bambu Studio 显示温湿度具体数值），打印机兼容性不变。
- ⚠️ **N3F05 已知风险**：旧版实测该机型名在部分打印机环境运行两次即被拉黑。本版测试环境未复现，但**未经充分长测**。若你遇到"用一阵被拉黑 / 掉线"，把 `bambu_bus_ams.cpp` 上报机型名改回 `AMS08` 重编即可（OLED 温湿度页仍可正常显示，不依赖上报名）。如更看重稳定不被拉黑、不需要 Studio 显示温湿度数值，建议自行改回 `AMS08`。
- 打印机固件建议不高于 **1.07.00**：Bambu 较新固件已把 BMCU 类设备拉黑，1.07.00 是还能被支持的上限，高于此版本 BMCU 将无法使用。

## 七、开发中（不稳定）· TPU 软料送料实验

> ⚠️ **实验性功能，仍在开发中、效果尚未稳定，不推荐日常主力使用。** 实测送料速度偏慢、部分型号仍不稳定，参数仍是初值，需成品板迭代校准。普通用户（只用 PLA/PETG）**完全不受影响**，走原 v3.2.1 刚性逻辑。

- **设计意图**：TPU 这类软料会被缓冲头压缩而非顺畅前进，旧版易误报堵料 / 啃料。v4.0 尝试按型号单独调参，并内置到所有固件。
- **绕开只能设 GFU98 的限制**：编译时给 4 通道分别写死型号（`BMCU_TPU_FIX0~3`，默认全 `GFU85`）；某通道设为 TPU for AMS（GFU98）时，固件忽略下发值、内部用写死型号跑；回传仍是 GFU98，不触发打印机重设；非 TPU 走刚性逻辑、写死表不参与；设 TPU 改回 PETG 实时恢复刚性、无残留。
- **当前建议**：TPU 只当试验，主力材料仍用 PLA/PETG；若某型号送料不理想，反馈现象一起调参。
